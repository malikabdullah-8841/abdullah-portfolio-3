# Abdullah Malik – Portfolio

Personal portfolio website of Abdullah Malik, Lead Full Stack & AI Engineer.

Live: https://malikabdullah-portfolio.netlify.app

## Structure

```
index.html        Page markup
css/style.css     All styles
js/main.js        Projects, skills and journey data, animations, counters, custom cursor
images/           Profile photo and project screenshots
netlify.toml      Netlify settings (no build step)
```

## Editing content

Projects, skills, numbers and the journey timeline live in arrays at the top of `js/main.js`.
Edit them there, commit and push. Netlify redeploys automatically.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
npx serve .
```
